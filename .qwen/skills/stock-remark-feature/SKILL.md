本技能实现了自选股备注功能，允许用户为自选股添加备注信息并在卡片中显示。

## 功能描述

1. 在自选股卡片底部显示备注信息
2. 默认显示"备注"字样
3. 双击备注可编辑并保存到数据库
4. 备注信息在所有自选股视图中保持同步
5. 备注文字固定显示为蓝色 (`#2080f0`)，与其他涨跌颜色区分

## 技术实现

### 后端修改
- 在 `FollowedStock` 结构体中添加 `Remark string` 字段
- 新增 `SetStockRemark(remark, stockCode string) string` 方法用于更新备注
- 在 `addStockFollowData` 函数中将备注字段从 `FollowedStock` 复制到 `StockInfo`

### 前端修改
- 在 `formModel` 中添加 `remark` 字段
- 在自选股卡片模板中添加备注显示区域，支持双击编辑
- 备注文字使用固定蓝色 `style="color: #2080f0;"` 显示
- 在设置弹窗中添加备注输入框
- 在保存逻辑中调用 `SetStockRemark` 方法更新备注

### 数据流
1. 用户双击备注 -> 弹出编辑对话框
2. 输入新备注 -> 调用 `SetStockRemark` API
3. 后端更新数据库 -> 返回成功消息
4. 前端刷新列表 -> 显示更新后的备注

## 验证方法

1. 构建项目：`wails build`
2. 启动应用并添加自选股
3. 双击任意股票卡片底部的"备注"文字
4. 输入新备注并保存
5. 观察卡片是否正确显示新备注
6. 刷新页面确认备注持久化

## 注意事项

- 备注信息通过数据库持久化存储
- 备注字段长度限制为50字符
- 所有自选股视图（全部标签页和分组标签页）均支持备注显示
